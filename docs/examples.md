# AgentPlat Examples

**Defines:** the executable-example index. **Status:** implemented documentation.

Begin with `examples/basic-runtime.mjs`, `examples/multi-agent-session.mjs`,
`examples/collective-runtime.mjs`, `examples/portable-agent-adapter.mjs`,
`examples/agent-morphogenesis/`, `examples/mesh-multiprocess/` and
`examples/rooms-api/`. Run the corresponding root `example:*` script after
building.

`pnpm run example:agent-morphogenesis` exercises the future-baseline
recruit-existing and catalog-create paths, including the crash/reconciliation
boundary, governed Workflow stages, detach/retirement and final receipts.
