# Agent Morphogenesis Strategy Adaptation V3 source acceptance checklist

Status: source-complete. Checkmarks below require direct source and
deterministic-test evidence and do not imply operational improvement.

## Learning and evidence

- [x] V3 definitions bind immutable local strategies, Morphogenesis policy,
  blueprint catalog, proposal generator and admitted operators.
- [x] Context binds mission scope, morphology epoch, need, target, risk, cost
  and deadline.
- [x] Selection reuses bounded local adaptation, baseline, exploration,
  quarantine, entropy and safety gates.
- [x] Selection is advisory and binds generator receipt, proposal and plan.
- [x] Only exact observed outcomes become five-metric causal feedback.
- [x] Partial/unsafe/indeterminate outcomes map conservatively.

## Governance and stability

- [x] Recommendations are persisted before review and grant no authority.
- [x] Agent, person and quorum reviews normalize to one exact review contract.
- [x] Proposer/reviewer independence, confidence, expiry and CAS are enforced.
- [x] Promotion, degradation, retirement and rollback are explicit transitions.
- [x] Baseline retirement and retired-strategy promotion fail closed.
- [x] Cooldown and bounded transition windows suppress oscillation.
- [x] Terminal recommendation IDs cannot reopen within a state generation.

## Counterfactual and simulation

- [x] Scenario binds simulator implementation, environment, seed, candidates,
  context, budget and lifetime.
- [x] Deterministic simulator replay yields an exact report digest.
- [x] Actual evidence can classify regression and damage conservatively.
- [x] Counterfactual estimates cannot enter the observed-feedback adapter.
- [x] Reports are advisory and require separate governance review.

## Integrations and persistence

- [x] Mission Lifecycle has an explicit opt-in strategy-change action.
- [x] Trust only narrows the existing strategy safety dimension.
- [x] AgentPlat Memory stores content-free non-authoritative recall records.
- [x] Agent Rooms and Agent Mesh project strategy records without authority.
- [x] PostgreSQL persists learner/governance state and counterfactual reports
  with CAS/digest checks and rollback witness.

## Public delivery

- [x] Runtime, host, PostgreSQL, Mission and Rooms/Mesh APIs have public type
  contracts.
- [x] ADR, specification, threat model and executable reference example exist.
- [x] Full workspace `pnpm check` passes on the final tree.

## Non-claims

The implementation does not prove that any strategy improves real mission
outcomes. Operational, cost, scale and comparative-effectiveness claims require
a separate preregistered empirical campaign.
