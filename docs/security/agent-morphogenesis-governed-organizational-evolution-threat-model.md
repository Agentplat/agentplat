# Agent Morphogenesis Governed Organizational Evolution V7 threat model

| Threat | Control |
| --- | --- |
| One anomaly triggers reorganization | Persistent consecutive-cycle evidence. |
| Monoculture or one provider/model dominates | Minimum provider/model diversity and concentration ceilings. |
| Unbounded population or churn | Team/member/changed-member limits. |
| Plan injects a new effect path | Only validated V1/V2/Topology artifacts and closed operators. |
| Dependency cycle hides authority ordering | Exact DAG validation. |
| Review grants all owner authorities | Authorization binds plan only; owner handoffs grant nothing. |
| Partition causes conflicting topology | Current topology digest and successor epoch are exact. |
| Canary replay fabricates stability | Observation IDs and evidence-bound receipts are idempotent. |
| Partial failure leaves half-applied organization | Durable intent and reverse compensation receipts. |
| Remote Mesh message executes change | Projection is unsigned and authority-neutral. |
| Database rollback reopens plan | Semantic validation, CAS and external witness. |

Residual risks include colluding reviewers, compromised evidence/simulators,
incorrect diversity classification and malicious owner adapters. Operational
validation remains separate.
