Zenodo assigns a DOI when the record is published. If the DOI must appear inside the PDF, create the draft, use **Get a DOI now!**, insert the reserved DOI into the manuscript and citation metadata, rebuild the PDF and checksums, and only then publish the draft. Otherwise, publish without an embedded DOI and cite the DOI assigned by Zenodo.

## Suggested description

Agent Mesh is a provider-neutral coordination substrate for independently executing agents operating with bounded local state and partial information. This paper specifies its reference composition with evidence provenance, distributed planning, adaptive organization, partition and topology policy, approval checkpoints, local inference control, mission continuity, compromise response, heterogeneous adapters, and effect-time enforcement. Version 1.2 adds the post-V28 evaluability certificate and publication-bundle reconstruction gate at source commit 490a392. The contribution is the explicit cross-layer contract separating information, agreement, assignment authority, and authorization of protected external effects. The manuscript also reports Campaign V28 as an inconclusive preregistered evaluation bound to the earlier commit f0412840; later source improvements are not treated as retrospective experimental evidence.
