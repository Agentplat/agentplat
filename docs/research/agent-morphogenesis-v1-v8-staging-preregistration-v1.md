# Agent Morphogenesis V1–V8 staging preregistration V1

Status: preregistered configuration only; execution is disabled.

The campaign evaluates the complete durable vertical on controlled independent
processes with PostgreSQL, Agent Mesh fault injection and a detached evidence
supervisor. It uses no production traffic.

The eight registered scenarios cover nominal completion, response loss after an
effect, PostgreSQL rollback, Mesh partition, constitutional fork, reverse
compensation, Trust restriction and Inference Control denial.

The campaign is falsifiable: any duplicate effect, stale-authority commit,
constitutional invariant violation, resource-ceiling violation or incomplete
terminal evidence rejects readiness. Passing the campaign may support a staging
readiness assessment only after separately authorizing execution and verifying
the resulting evidence bundle. It cannot establish production readiness or
organizational improvement.

The machine-readable registration is
`config/agent-morphogenesis-v1-v8-staging-preregistration-v1.json`.
