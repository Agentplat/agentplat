# AgentPlat Collaboration Protocol

**Defines:** the conceptual flow for messages, artifacts, planning and ownership handoffs. **Status:** specified and partially implemented across rooms, sessions, planning-artifacts and collective-runtime packages.

Participants exchange typed events and artifacts within a scoped room or session. A planner proposes work, agents produce evidence-bearing artifacts, and a handoff transfers bounded context and ownership. Persistence, authorization and audit are adapter/runtime responsibilities.
