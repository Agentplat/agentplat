# AgentPlat-compatible runtimes

**Defines:** the public compatibility declaration and conformance entry point. **Status:** specified.

Implementations may claim levels 1–4 only after passing the corresponding normative fixtures and tests. Level 1 is Agent Rooms; Level 2 adds artifacts, handoffs and scoped memory; Level 3 adds Collective Runtime; Level 4 adds Agent Mesh. Third-party implementations can publish a report linking their version, test output and supported level.
