# ADR 0050: Compose Agent Genesis from existing authority owners

Status: accepted

## Decision

Agent Morphogenesis V6 adds a durable orchestration layer around existing V2
synthesis, Governed Agent Factory, Membership, attestation, Trust, Inference
Control, Rooms, Mesh and Work boundaries. It does not introduce a new factory,
membership mechanism, Work issuer or action authority.

Generation produces an inert V2 profile. Sandbox and probation precede a
reviewed admission. Membership, attestation and retirement remain explicit,
reconcilable external operations. A Work handoff is evidence, never a Work
Contract or Action Grant.

## Consequences

- An agent, person or quorum may perform policy-authorized review.
- Creation and enrollment cannot be inferred from a favorable model output.
- Crashes replay stable operation IDs and do not authorize duplicate effects.
- Retirement after external admission requires a terminal compensation receipt.
- Local deployments retain their own policies and authority owners.
- Real-world quality and safety require separate empirical validation.
