# AgentPlat 1.6.0 preparation

Status: prepared source candidate; publication is verified separately.

This compatible minor release adds `groq`, `mistral`, `azure` and `bedrock` to
`ChatModelProvider` and the existing `chatModel` factory. No provider SDK or new
adapter abstraction is introduced. `AgentPlat.ask` and `AgentPlat.configure`
accept these presets through their existing typed options.

Azure OpenAI / Microsoft Foundry and Amazon Bedrock require an explicit API-root
`baseURL` and credentials by default. They use OpenAI-compatible Chat Completions
with bearer authentication. Azure deployment names are supplied as the model;
Bedrock callers supply a model supported in the configured region. AWS SigV4,
Converse, InvokeModel, legacy Azure APIs and Responses are outside this profile.

The coordinated release retains all 70 published packages and the existing
storage/protocol contracts. Upgrade selected `@agentplat/*` dependencies together
to the same exact version after registry verification. No migration is added.

See the [adapter guide](../../packages/model-openai-compatible/README.md) for
configuration, provider limitations and the joint smoke command. Unit tests use
mocked HTTP. A live smoke run must separately verify generation and streaming
for each selected provider/model; these checks do not qualify production scale
or all tool, vision and structured-output combinations.

Required publication path: protected-main checks, governance verification,
dry-run preparation and exact-artifact consumer checks, then the existing
release-level OIDC approval and public registry/provenance/consumer verification.
