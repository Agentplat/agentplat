## Capabilities and adoption

1.5.0 adds optional native Room conversation references and selective context;
incremental event/evidence identities and recoverable projection; versioned
situations and reviewed learning; shared periodic budgets with category holds;
timestamp intents and prepared notice delivery with explicit uncertainty.

See [1.5 adoption](1.5.0-adoption.md), [conversations](../planner/conversations.md),
[incremental follow-up](../planner/incremental-followup.md) and
[shared budgets/notices](../planner/shared-budgets-and-notices.md). Install only
the required packages, at the same exact coordinated version, and keep a lockfile.

Base Room migration 020 is explicit. The optional memory/evidence/follow-up/
operations ledgers remain independent; Workflows 001 and artifacts 002 are
unchanged. Adapter construction does not migrate or activate features. Qualify a
non-production copy and coordinate older-adapter shutdown before schema changes.

These checks establish distribution and bounded integration behavior. They do
not prove production-scale reliability, model judgment or arbitrary transport
delivery. Applications retain verified identity, policy, prices, provider and
device integration, migration operations and activation. Grishen application
adoption is separate from this library release and does not follow automatically
from publishing packages.
