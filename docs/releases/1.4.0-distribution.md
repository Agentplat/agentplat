## Release capabilities

- **AgentPlat Planner**: opt-in concurrent Room objectives, shared monetary reservations, versioned plans/reports, governed review and a bridge to durable workflow attempts. See [Planner adoption](room-planner-1.4.0-adoption.md).
- **Persistent memory and reviewed definitions**: stable-agent subjects with independently authorized personal/shared audiences, immutable correction and retirement, exact context references and review coordinates in existing governance history. See [persistent memory adoption](../getting-started/persistent-memory-consumer.md).
- **Artifacts**: optional tenant-scoped immutable revisions, PostgreSQL CAS persistence, transactional outbox and opt-in agent tools. Supported inert formats are Markdown, text, code, CSV, HTML and syntactically validated JSON. These packages do not generate PDF/XLSX/PPTX.

## Install

Install the packages used by an application at the same coordinated version:

```sh
npm install --save-exact @agentplat/framework@1.4.0 @agentplat/rooms@1.4.0 @agentplat/rooms-postgres@1.4.0
```

Add only the optional adapters and profiles needed. See the [public package catalog](../capability-catalog.md), [Planner guide](room-planner-1.4.0-adoption.md) and [persistent memory consumer guide](../getting-started/persistent-memory-consumer.md). Artifact package details are in the versioned [package README](https://github.com/Agentplat/agentplat/blob/efb6e976a98b487d7e82d05e64d6b0f7be6f22ca/packages/artifacts/README.md).

## Schema and activation

Planner requires explicit Rooms migration 019 and workflows migration 001 in the intended schema; the optional memory ledger remains a separate opt-in migration. Adapter construction does not apply migrations. Follow each guide's backup, migration-status and recovery procedures before enabling features. Artifact PostgreSQL migration application is likewise explicit; review the pinned package README and use an application-controlled migration process.

Agents.Grishen integration is separate work and is not included in this package release. Registry consumers use deterministic fixtures and isolated schemas; they are not a production-scale qualification.
