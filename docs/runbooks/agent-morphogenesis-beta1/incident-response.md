# Agent Morphogenesis Beta 1 incident-response runbook

Pause new scenarios at the next receipt boundary. Record the supervisor state,
heartbeat age, source SHA, active authorization digest, current scenario,
Temporal Workflow ID, PostgreSQL schema and Mesh membership epoch.

Classify unauthorized activation, duplicate material effect, lost receipt or
morphology-head fork as a terminal readiness failure. Preserve databases,
Temporal history, Mesh state, event journal and logs. Do not rerun or exclude a
failed sample. Resume only after the owning adapter can reconcile its stable
operation ID and the incident amendment is recorded.
