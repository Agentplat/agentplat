# AgentPlat Agent Morphogenesis V1

**Defines:** the future-baseline compatibility contract for governed,
mission-scoped organizational evolution. **Status:** opt-in source capability;
not part of the frozen AgentPlat compatibility-level V1 denominator.

## Normative definition

AgentPlat Agent Morphogenesis is the governed, mission-driven evolution of an
agent collective's operational form through creation, recruitment,
reconfiguration, detachment and retirement while preserving causal continuity,
bounded authority and auditable evidence.

A conforming V1 implementation:

1. observes only authenticated, bounded and scope-current source heads;
2. distinguishes a need, target, proposal, decision and enacted effect;
3. binds every proposal to one current morphology epoch and a closed process
   definition;
4. supports policy-selected authorized-agent, authorized-person, local-policy,
   collective or composite decisions;
5. treats every proposal, gate, profile, capability claim and factory receipt
   as non-authoritative outside its owning boundary;
6. uses existing governed lifecycle, membership, Team, individual Work and
   Action Gateway authority;
7. journals stable operation identities before external effects and reconciles
   ambiguous outcomes rather than replaying them blindly;
8. advances one successor morphology head through revision-and-digest CAS;
9. checkpoints useful work and fences Work/action authority before detachment
   or external resource termination;
10. retains content-free causal events and receipts while excluding credentials,
    private keys, raw prompts, raw model output and hidden reasoning; and
11. distinguishes source/conformance behavior from organizational improvement,
    production readiness and global optimality.

## First-release operator profile

The V1 public profile admits `recruit_existing`, `instantiate_agent` from a
certified catalog profile, `detach_agent` and `retire_agent`. Derived or
synthesized profiles, recursive creation and Team split/merge/federation remain
outside this profile.

## Compatibility

The public entry point is
`@agentplat/collective-runtime/morphogenesis`. Generic process execution is
provided by Governed Durable Workflows. Application/provider adapters remain
replaceable only when AgentPlat state, decisions and authority boundaries stay
authoritative.

Conformance with this document is additive. It does not change an
implementation's AgentPlat compatibility level 1–4 claim until a future
baseline manifest explicitly incorporates Agent Morphogenesis.
