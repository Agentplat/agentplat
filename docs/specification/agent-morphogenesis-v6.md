# AgentPlat Agent Morphogenesis Governed Agent Genesis V6

**Defines:** additive, opt-in synthesis, sandboxing, probation and governed
admission of a new agent profile when no approved blueprint satisfies an
evidenced need. **Status:** source capability; no autonomous-production or
effectiveness claim.

V6 reuses V2 synthesized profiles, authority attenuation and independent
synthesis certification. It also reuses the existing Governed Agent Factory,
Membership lifecycle, runtime attestation, Trust, Inference Control, Agent
Rooms, Agent Mesh and Work owners. It creates no alternate authority plane.

## Required separation

The stages are distinct and durable:

1. demonstrate a blueprint gap and bind a certified V5 strategy;
2. generate a content-free V2 synthesized-profile draft;
3. validate provenance, model/artifact bindings, budgets and attenuation;
4. evaluate all required adversarial threats;
5. persist and prepare an isolated sandbox with a stable operation ID;
6. review entry into probation;
7. collect bounded capability, Trust and Inference Control receipts;
8. review admission through an agent, person or quorum;
9. apply the existing Membership lifecycle;
10. attest the resulting instance;
11. hand verified material to existing Team/Work owners; and
12. suspend, compensate and retire through the existing retirement boundary.

No stage substitutes for a later stage.

## Need and draft

`MorphogenesisAgentGenesisNeedV6` binds mission scope, Morphogenesis need,
certified V5 strategy and local/collective evidence. Genesis is unavailable
while any evaluated blueprint remains eligible.

`MorphogenesisAgentGenesisDraftV6` contains an exact
`AgentInstantiationProfileV2` and its evolution, authority attenuation and
independent synthesis certification context. Generator/model/artifact/provenance
coordinates and ceilings are digest-bound. The schema has no arbitrary code,
prompt, credential or unrestricted output field. A draft is inert.

## Evaluation, sandbox and probation

Evaluation requires prompt injection, tool escalation, memory exfiltration,
data exfiltration, identity spoofing, recursive spawning and resource
exhaustion assessments. Baseline, simulator implementation, environment, seed,
interaction budget, assessor and evidence are retained.

Sandbox preparation is two-phase: persist the operation, invoke the
application-owned sandbox with the stable ID, then commit its receipt. The
receipt explicitly denies Membership, Work and Action Authority.

Probation receipts are content-free and idempotent. Each binds capability
evidence and current Trust and Inference Control decisions. Policy limits the
observation count and sets minimum successes and maximum unsafe outcomes.

## Governance, admission and compensation

Lifecycle states are `draft`, `sandboxed`, `probationary`, `admitted`,
`suspended` and `retired`. Transitions use exact recommendations and reviews by
an authorized agent, authorized person or collective/quorum. Reviewer
independence is policy-controlled.

An admitted record still has no external authority. Membership is applied only
through `MorphogenesisAgentLifecyclePortV1`; runtime attestation follows as a
separate operation. Work and Action Authority remain false. The activation
handoff can only provide verified material to their existing owners.

Reviewed retirement first suspends the entry. The existing retirement port
then removes Membership/terminates the resource and returns a terminal receipt.
Only that receipt advances the entry to `retired`. Replay and crash recovery
reuse exact operation IDs.

## Persistence and projections

PostgreSQL stores lifecycle state with semantic validation, revision/digest CAS
and an external rollback witness. Agent Rooms artifacts and Agent Mesh
projections are content-free and authority-neutral. Genesis lineage binds need,
draft, profile evolution, attenuation, synthesis certification, factory
lineage, Membership, attestation and terminal evidence without granting
authority.

## Evidence boundary

Deterministic tests establish source behavior, not that generated agents are
useful, safe under every attack or ready for unsupervised production use.
