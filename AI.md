# AgentPlat AI Context

AgentPlat is an open-source TypeScript framework for persistent human-agent collaboration, with shared artifacts, human approvals and controlled execution on your infrastructure.

AgentPlat Agent Rooms provide the collaboration workspace. AgentPlat Collective Runtime and AgentPlat Agent Mesh add planning and distributed coordination when needed. AgentPlat is a developer preview; source availability, registry distribution and operational evidence must be checked separately.

## Agent Morphogenesis capability map

- V1–V2: governed lifecycle, synthesized profiles, Dynamic Topology and compensation.
- V3: bounded local strategy adaptation and agent/person/quorum governance.
- V4: content-free collective strategy evidence and convergence over Agent Mesh.
- V5: governed strategy synthesis, adversarial simulation and canary catalogs.
- V6: governed Agent Genesis with sandbox, probation, Membership and retirement.
- V7: whole-collective organizational evolution with multi-owner compensation.
- V8: constitutional continuity, longitudinal proofs, meta-governance and fork isolation.

All V3–V8 surfaces are opt-in source capabilities. Their integration-hardening
status and remaining operational obligations are tracked separately in
`config/agent-morphogenesis-hardening-v1.json`; they are not part of the frozen
Collective Capability Baseline V1 denominator.
